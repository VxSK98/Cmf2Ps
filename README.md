# Cmf2Ps

`Cmf2Ps` - UXP-плагин для Adobe Photoshop, который связывает документ Photoshop с локальным `ComfyUI`.
Плагин умеет:

- Задать выделение по разным пресетам;
- Отправлять выделенную область или весь документ в ComfyUI как snapshot;
- Поддерживать режим `InpaintMask` для workflow, которые умеют работать с дополнительной маской;
- Отправлять ref-изображение в отдельную ref-ноду;
- Делать ref-файл из выделенной области или документа, именовать и отправлять в папку рефов comfy. Так же можно удалять по имени
- Весь рабочий процесс динамически настраивается через интерфейс ComfyUI, который встроен в плагин;
- Принимать результаты обратно в Photoshop и показывать их в окне превью.

## Как это работает

Базовый сценарий такой:

1. В Photoshop выбирается область или слой.
2. `Cmf2Ps` делает snapshot, собирает маску и отправляет PNG в локальный ComfyUI
3. В workflow ComfyUI входные данные читаются через ноды `CMF2PS_LoadImage` и `CMF2PS_LoadRef`.
4. Результат из ComfyUI отправляется обратно через `CMF2PS_SendToPhotoshop`.
5. Плагин показывает варианты в списке превью и позволяет вставить выбранный результат в документ.

## Требования

- Adobe Photoshop с поддержкой UXP (`host.minVersion` в манифесте: `23.0.0+`).
- Локально запущенный `ComfyUI`.
- Установленное backend-расширение `backend/comfyui-cmf2ps` в папку `ComfyUI/custom_nodes/`.

Важно: по умолчанию плагин использует сервер ComfyUI на `http://127.0.0.1:8188`, но адрес можно изменить в настройках.
Выходное изображение желательно должно быть в том же разрешении, что и оригинал. Иначе включить `Масштабирование слоя`
Желательно: задать ppi документа на значение 72

## Установка

### 1. Подключить UXP-плагин в Photoshop

### 2. Установить backend в ComfyUI

Установить backend и ноды через пункт в настройках: выбрать папку .../ComfyUI/custom_nodes и нажать кнопку установки
После этого перезапустить/запустить ComfyUI.

### 3. Проверить, что связка поднялась

После запуска:

- Photoshop должен открыть панель `Cmf2Ps`;
- Веб-окно должно показывать интерфейс ComfyUI;
- workflow в ComfyUI должен использовать ноды категории `CMF2PS`.

## Ноды ComfyUI

Backend регистрирует 4 основные ноды:

- `CMF2PS_LoadImage`
  Загружает snapshot и маску, пришедшие из Photoshop.
- `CMF2PS_LoadRef`
  Загружает ref-изображение, присланное из Photoshop.
- `CMF2PS_SendToPhotoshop`
  Отправляет итоговые изображения обратно в панель Photoshop.
- `CMF2PS_NormalToAO`
  Генерация карты высот и AO из нормала

Типовой pipeline:

Photoshop -> CMF2PS_LoadImage / CMF2PS_LoadRef -> ваш workflow -> CMF2PS_SendToPhotoshop

!!! Для работы нод с внешним вызовом нужно выполнить вход, используя ключ api 

## Основные элементы панели

### Задать выделение

Кнопка `Задать выделение` создает прямоугольное выделение по одному из пресетов размеров.
Можно центрировать его по документу или по текущей области, в зависимости от состояния переключателя центра.

### Генерация

Кнопка `Генерация`:

- подготавливает snapshot;
- при необходимости отправляет `InpaintMask`;
- запускает генерацию в ComfyUI.

Рядом находится счетчик количества запусков генерации. Сейчас в интерфейсе поддерживается диапазон от `1` до `5`.

- Если выделение не задано, то автоматически выделится весь документ. При обработки всего документа рекомендуется выставить значение паддинга на 0.
- После генерации если надо что-то догенерить, то лучше через кнопку "Запустить". Кнопка генерации сбросит все превью и заново сделает снапшот и генерацию по новому снапшоту.

### Padding слоя +

Слайдер `Паддинг слоя +` расширяет область вокруг выделения или слоя перед экспортом snapshot.
Это влияет на то, сколько контекста уйдет в ComfyUI.

### Масштабирование слоя

Включение этого параметра позволяет скейлить изображение под текущие габариты. Пригодится, если, например, в рабочем процессе есть этапы апскейла/изменения размера

### Маскировать слой

Опция `Маскировать слой` управляет применением маски к полученному результату

### Растушевка

Слайдер `Растушевка` задает blur к примененной маски.


### Режим InpaintMask

Кнопка `Режим InpaintMask` включает сценарий с дополнительной маской.
Он нужен для workflow и моделей, которые поддерживают прямую работу с inpaint mask.

### Реф-нода

Блок `Реф-нода` позволяет:

- вырезать ref из текущего документа;
- отправить его в ComfyUI;
- быстро переотправить один из сохраненных ref через список превью.

Блок `Реф-папка` позволяет:

- Делать ref-файл из выделенной области или документа;
- задать имя и отправить его в папку ComfyUI/input;
- удалить файл из папки по заданному имени.

### Окно предпросмотра

Плагин принимает изображения из ComfyUI, складывает их в список превью и позволяет:

- выбрать нужный вариант;
- посмотреть его в панели;
- применить выбранный результат в Photoshop;
- очистить список превью.

## Шаблоны workflow

В папке `test_workflows/` лежат примеры и шаблоны workflow. Их можно использовать как стартовую точку и адаптировать под свои ноды, модели и пайплайн.

Если workflow должен работать с `Cmf2Ps`, в нем обычно нужны:

- нода загрузки snapshot;
- нода загрузки ref, если используется reference input;
- финальная нода отправки результата в Photoshop.
